# Sharaga Info Bot

Telegram-бот по Obsidian-хранилищу [KAIT20-INFO](https://github.com/TeamKait/KAIT20-INFO):
преподаватели, предметы и заметки

| Команда | Что делает |
|---|---|
| `/start` | справка |
| `/teacher` | список преподавателей |
| `/teacher <имя>` | заметка преподавателя: фото, почта, предметы |
| `/teacher <имя> предметы` | какие предметы ведёт |
| `/email <имя>` | почта преподавателя |
| `/subject` | список предметов |
| `/subject <название>` | информация о предмете |
| `/find <запрос>` | найти заметку целиком |
| `/sync` | обновить данные из GitHub |
